NPM (Node Package Manager) — это менеджер пакетов для JavaScript, используемый для установки, управления и публикации 
библиотек и зависимостей в проектах, работающих на Node.js. 

Он позволяет разработчикам легко подключать сторонние модули, управлять версиями и автоматизировать задачи разработки. 

NPM состоит из двух основных компонентов:

1. **CLI (интерфейс командной строки)**: Используется для выполнения команд, таких как установка пакетов (`npm install`), 
запуск скриптов (`npm run`) или публикация модулей.
2. **Реестр npm**: Онлайн-репозиторий, где хранятся тысячи JavaScript-пакетов, доступных для загрузки.

Пример использования:

```bash
npm install express
```
Эта команда устанавливает фреймворк Express в ваш проект.

NPM автоматически создаёт файл `package.json`, где хранится информация о проекте и его зависимостях. Это стандартный 
инструмент для большинства JavaScript-разработчиков.
